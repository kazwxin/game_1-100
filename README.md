# game_1-100
Игра на угадывание числа от 1 до 100 с компьютером
Игра предпологает взаимодействие человека с компьютером, где есть возможность как самому загадать число, так и угадывать число от комьютера.
Также добавлена функция вывода числа, если человек не может угадать или хочет сдаться.
Программный блок разделен на 6 функций:
1. clear_input_buffer()
  Очищает буфер ввода после чтения данных. Нужна для предотвращения "залипания" старых данных при повторных вводах.
2. safe_int_input(prompt, min_val, max_val)
  Безопасный ввод целого числа с проверками:
  Не даёт ввести буквы или пустую строку
  Проверяет, что число в указанном диапазоне (если задан)
  Повторяет запрос, пока пользователь не введёт корректное значение
3. guess_with_hint(prompt, min_val, max_val, allow_zero)
  Специальный ввод для режима, где игрок отгадывает:
  Обычно требует число от 1 до 100
  Если allow_zero=True, то 0 означает "сдаюсь"
  Выдаёт понятные сообщения об ошибках
4. computer_guesses()
  Режим "Компьютер отгадывает":
  Игрок задумывает число
  Компьютер угадывает методом бинарного поиска (делит диапазон пополам)
  Игрок отвечает: 1 (угадал), 2 (больше), 3 (меньше)
  Выводит количество попыток
5. player_guesses()
  Режим "Игрок отгадывает":
  Компьютер загадывает случайное число от 1 до 100
  Игрок вводит свои варианты
  Компьютер подсказывает "больше" или "меньше"
  Можно ввести 0, чтобы сдаться и узнать число
  Выводит статистику после угадывания
6. main()
  Главная функция:
  Показывает меню выбора режима
  Запускает выбранный режим
  После окончания игры спрашивает "сыграть ещё?"
  Обрабатывает выход из программы
Также в конце написана защита: if __name__ == "__main__"
На случай если игра была прервана пользователем.
